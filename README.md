# PySnip

Python / PySide6로 만든 Windows용 캡처·이미지 고정 기본 앱입니다.

## 실행

배포본은 ZIP을 풀고 **PySnip.exe**를 실행하면 됩니다. Python 설치는 필요하지 않습니다. OCR 언어가 없는 PC에서는 앱의 **설정 → OCR 언어 활성화 / 설치 상태**로 설치하세요. 단일 EXE는 실행 시 임시 폴더에 구성 요소를 풀기 때문에 최초 실행이 잠시 걸릴 수 있습니다.

Python 3.10 이상에서 이 폴더를 터미널로 열고 실행합니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 사용법

- **F1**: 화면 영역을 드래그하면 클립보드에 복사하고 항상 위에 표시되는 창으로 고정합니다.
- **F3**: 클립보드의 이미지를 새 창으로 고정합니다.
- 캡처 중 **Esc / 우클릭**: 취소합니다.
- 고정 창 **드래그**: 이동, **휠**: 확대·축소, **Ctrl+휠**: 투명도 조절.
- 고정 창 **Ctrl+C**: 원본 복사, **Ctrl+S**: 원본 PNG 저장, **0**: 원래 크기, **Esc**: 닫기.
- 고정 창을 우클릭해 복사·저장·닫기를 실행할 수도 있습니다.
- 메인 창·트레이·이미지 우클릭 메뉴의 **설정**에서 단축키와 불투명도(20~100%), 테두리(0~20px)를 함께 관리합니다. 저장하면 열린 모든 이미지와 새 이미지에 공통 적용되며 재실행 후에도 유지됩니다. **Ctrl+휠도 전체 이미지의 불투명도를 변경하고 저장**합니다. 기본값은 불투명도 100%, 테두리 1px입니다. 기존 INI의 두께는 유지되며 0px로 선을 없앨 수 있습니다. 테두리는 이미지 바깥에 표시되고 확대·축소와 무관한 두께를 유지합니다. px는 Windows 배율이 적용되는 화면 논리 픽셀입니다. 복사·저장·OCR에는 원본 이미지를 사용합니다.
- 메인 창의 X 버튼은 트레이로 숨깁니다. 완전히 종료하려면 앱 또는 트레이 메뉴의 **종료**를 사용합니다.

**설정**에서 Ctrl/Alt/Shift과 기능키·문자·숫자를 조합하고 **저장**하면 단축키가 적용됩니다. 전체 기본값 복원을 누른 뒤 저장하면 F1/F2/F3, 불투명도 100%, 테두리 1px, OCR 한국어로 돌아갑니다. **취소**하면 저장 전 변경을 적용하지 않습니다. 고정 창 내부의 Ctrl+C/Ctrl+S 등은 변경 대상이 아닙니다.

여러 기능에 같은 단축키를 지정할 수 없습니다. 다른 앱이 점유한 조합은 안내 후 기존 설정을 유지합니다. 시작할 때 저장된 단축키 등록에 실패하면 전역 단축키는 비활성화되지만 버튼과 트레이 메뉴는 사용할 수 있습니다. 설정 창에서 다른 조합을 저장해 다시 활성화하세요. 설정 중에는 전역 단축키 동작을 잠시 억제합니다. 문자·숫자에는 보조키가 필요하며 F12는 Windows 예약 키여서 제외했습니다. 설정은 EXE 옆의 PySnip.ini에 저장합니다.

## 포터블 설정

Win 키를 포함한 조합은 Windows 예약 영역이므로 등록하지 않습니다. Alt+F4(창 닫기), Ctrl+C/S/T/E/L(앱의 복사·저장·OCR·편집·잠금)도 전역 단축키로 지정할 수 없습니다. 설정에서 선택 즉시 이유를 표시하고 저장 버튼을 비활성화합니다. 다른 앱의 점유 여부는 저장 시 Windows 등록 API로 검사하며 실패하면 기존 단축키를 유지합니다. 이전 INI의 제한 조합은 임의로 덮어쓰지 않고 설정에서 수정하도록 안내합니다. 예약 기준: [Microsoft RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey).

단축키 목록은 F1~F11, 영문자, 숫자 1~0으로 구성합니다. **숫자를 선택하면 Num 체크박스가 표시**됩니다. 체크하면 숫자패드, 해제하면 상단 숫자열입니다. 예: `Ctrl+1`, `Ctrl+Num1`. 문자·기능키를 선택하면 Num은 숨겨지고 해제됩니다. 기존 Num 단축키는 자동으로 체크 상태로 불러옵니다. 숫자패드는 Num Lock을 켜고 사용하세요(Shift 조합은 Windows의 숫자패드 탐색키 전환에 영향을 받을 수 있습니다). F12는 Windows 예약 키이며 F13~F24는 새 선택 목록에서 제외했습니다. 이전에 저장한 F13~F24는 기존 설정으로 표시하고 유지합니다.

첫 실행 시 **PySnip.exe와 같은 폴더의 PySnip.ini**를 자동 생성합니다. 소스 실행 시에는 main.py 폴더에 생성합니다. EXE와 INI를 함께 복사하면 다른 폴더·PC에서도 설정을 유지합니다. EXE 업데이트 시 기존 INI를 그대로 보관하세요. ZIP에는 개인 설정을 포함하지 않습니다.

INI가 없을 때만 이전 버전의 레지스트리 설정을 가져오며, 이전 설정도 없으면 기본값을 사용합니다. 기존 INI가 있으면 레지스트리는 참조하지 않습니다. 쓰기 권한이 없는 폴더에서는 저장 실패를 안내하므로 쓰기 가능한 폴더에서 실행하세요. 직접 수정할 때는 앱을 종료한 뒤 편집하세요.

```ini
[Hotkeys]
capture=F1
clipboard=F3

[Appearance]
opacity=100
border=1

[OCR]
language=ko-KR
retry_scale=2
```

Windows OCR 언어 기능은 PC에 설치되는 구성 요소이므로 다른 PC에서는 설치 상태를 다시 확인해야 합니다.

## OCR (Windows 10 이상)

- **설정 → OCR 언어 활성화 / 설치 상태**에서 실제 사용 가능한 언어를 확인합니다. OCR 기본 언어도 설정 창에서 선택하고 저장합니다.
- 누락된 언어가 있으면 **한국어·영어 활성화 (관리자 권한)**를 누르고 Windows UAC 요청을 허용하세요. 한국어·영어의 Basic/OCR Windows 선택적 기능 중 누락된 항목만 설치합니다. 인터넷과 Windows Update 접근이 필요하고 몇 분 이상 걸릴 수 있습니다. 회사 정책 등으로 설치가 막히면 오류를 표시하며 다시 시도할 수 있습니다. 표시 언어는 바꾸지 않습니다.
- 고정 이미지에서 **우클릭 → 텍스트 추출 OCR** 또는 **Ctrl+T**를 누르면 자동으로 인식합니다. 결과 창에는 텍스트 영역만 표시되며 수정·선택·Ctrl+C 복사가 가능합니다(Ctrl+A로 전체 선택). 기본 언어는 한국어이며 한글·영문 혼합 문서에 사용할 수 있습니다. 설정한 언어가 설치되어 있지 않으면 설치된 다른 지원 언어를 사용합니다. 두 언어 모두 없으면 설정에서 설치하도록 안내합니다. 두 엔진의 결과를 자동 병합하거나 표 서식을 복원하지는 않습니다.
- OCR은 Windows 내장 엔진과 Windows PowerShell 5.1을 사용합니다. 추가 Python OCR 패키지, API 키가 필요하지 않으며 이미지는 외부로 전송하지 않습니다. 임시 PNG는 작업 종료 시 삭제됩니다. 큰 이미지는 엔진의 최대 크기에 맞춰 축소하므로 작은 글자의 인식률이 떨어질 수 있습니다.
- OCR 진행 중에도 앱을 사용할 수 있으며 창을 닫으면 인식 작업을 중단합니다. 언어 설치 중에는 해당 창을 닫을 수 없습니다. 앱을 완전히 종료하더라도 이미 시작한 Windows 언어 설치는 시스템에서 계속 진행될 수 있습니다. 설치 후 재시작 필요 여부 및 실제 OCR 사용 가능 여부를 다시 확인합니다.
- **설정 → OCR → 확대 후 인식 시도**에서 **하지 않음 / 2배 / 4배** 중 하나를 선택합니다(기본 2배). 원본에서 텍스트를 찾지 못하거나 인식 엔진이 실패하면 선택한 배율로 한 번만 재시도합니다. 하지 않음은 원본 인식만 수행합니다. INI의 `OCR/retry_scale` 값은 각각 1/2/4입니다. 확대 이미지나 배율은 결과 창에 표시하지 않습니다. 작은 이미지에는 OCR용 사본에 흰 여백을 보충합니다. 언어 미설치·실행 실패에는 확대 재시도하지 않습니다. 엔진 한도와 최대 4096px 범위 안에서만 처리하며 화면에 고정된 이미지·저장 원본은 바꾸지 않습니다.

참고: [Microsoft Windows OCR](https://learn.microsoft.com/en-us/uwp/api/windows.media.ocr.ocrengine), [OCR 언어 설치](https://learn.microsoft.com/ko-kr/windows/powertoys/text-extractor).

## 현재 범위

각 모니터 안에서 영역을 선택할 수 있습니다. 서로 다른 모니터에 걸친 하나의 영역 선택, 주석·모자이크, 캡처 기록, 재시작 시 고정 창 복원은 아직 구현하지 않았습니다. 고정된 이미지는 다음 캡처에도 포함됩니다. 화면 배율은 원본 캡처의 devicePixelRatio를 사용해 처리합니다. 실제 복합 DPI 모니터 구성은 별도 검증이 필요합니다.

화면 캡처 API 참고: [Qt QScreen](https://doc.qt.io/qtforpython-6/PySide6/QtGui/QScreen.html).

## EXE 빌드

```powershell
python -m pip install pyinstaller pillow
python build_release.py
```

dist/PySnip.exe와 dist/PySnip-Windows-x64.zip을 생성합니다. 빌드 후 EXE 자체로 아이콘·전역 설정·OCR 도우미·다중 이미지 종료를 검사합니다. 생성된 EXE에는 코드 서명이 포함되어 있지 않습니다.

### 추가 기능
- 중복 실행 시 기존 PySnip 창을 표시합니다. 비정상 종료 후에는 다음 실행에서 잠금을 복구합니다.
- **F2**: 고정 이미지 전체 숨김/복원. 설정에서 변경할 수 있으며 메인 창과 트레이 메뉴에서도 실행할 수 있습니다. 위치와 확대율은 유지됩니다. 숨김 상태에서 추가한 이미지도 복원할 때 함께 표시됩니다.
- **설정 → OCR → 인식 결과 자동 복사**: 기본값은 꺼짐입니다. 켜면 인식에 성공한 비어 있지 않은 결과만 클립보드에 복사하며, 결과 창은 계속 표시합니다. 실패·빈 결과·취소 시 기존 클립보드를 유지합니다.
- 자동 복사 설정은 `PySnip.ini`의 `[OCR] auto_copy`, 숨김/복원 단축키는 `[Hotkeys] toggle`에 저장됩니다.

빌드는 사용자가 명시적으로 요청한 경우에만 수행합니다.

### 종료 후 고정 이미지 복원
설정의 **다음 실행 시 고정 이미지 복원**을 켜면 정상 종료 시 열려 있던 이미지 원본, 위치, 확대율을 `PySnip.session.json`에 저장합니다. 기본값은 꺼짐입니다. 다음 실행에는 숨겨둔 이미지도 표시하며 현재 전역 투명도·외곽선 설정을 적용합니다. 모니터 변경으로 화면 밖에 놓인 이미지는 기본 화면으로 이동합니다. 닫은 이미지는 다음 종료 저장에서 제외됩니다. 옵션을 끄고 저장하면 기존 복원 파일도 삭제됩니다. 포터블 이동 시 EXE, INI와 복원 파일을 함께 옮기세요.
프로그램이 완전히 종료된 동안에는 이미지를 표시하지 않습니다. 이 옵션은 다음 실행 시 복원하는 기능이며 강제 종료·충돌 직전 상태의 자동 저장은 포함하지 않습니다.

### 실행 시 표시 방식
최초 실행은 메인 창을 표시하고, 이후에는 트레이로 시작합니다. 실행 이력은 `PySnip.ini`의 `[Startup] has_started`에 기록됩니다. 이 항목이 없는 기존 설정도 변경 후 첫 실행에는 메인 창이 표시됩니다. 트레이를 사용할 수 없거나 INI 저장 오류가 있으면 메인 창을 표시합니다. 고정 이미지 복원 옵션은 트레이 시작 때도 적용됩니다. 트레이 더블 클릭 또는 메뉴의 **메인 창 열기**로 창을 표시할 수 있으며, 앱을 다시 실행해도 기존 창이 열립니다.


## 버전 관리

현재 소스 버전은 **0.2.0**입니다. `version.py`에서 관리하고 변경 내역은 `CHANGELOG.md`에 기록합니다. 버전 태그는 `v0.1.0` 형식을 사용합니다. 배포 ZIP은 명시적으로 빌드할 때 `PySnip-0.2.0-Windows-x64.zip` 형식으로 생성됩니다. 개인 INI, 이미지 복원 데이터와 빌드 결과물은 Git에 포함하지 않습니다.


## 닫은 이미지 복원·잠금·편집 (0.2.0)

- 메인 창 또는 트레이의 **마지막 닫은 이미지 복원**으로 최근에 닫은 이미지부터 되살립니다. 원본, 위치, 확대율과 잠금 상태를 유지합니다. 설정의 **닫은 이미지 보관 개수** 기본값은 **0(무제한)**이며, 양수를 지정하면 오래된 기록부터 제외합니다. 기록은 실행 중 메모리에 보관하며 종료하면 비워집니다. 무제한 보관 시 이미지 수에 따라 메모리 사용량이 늘어납니다. 설정값은 INI의 `[History] limit`에 저장됩니다.
- 이미지 우클릭 → **이동·크기 잠금** 또는 **Ctrl+L**: 드래그, 휠 확대·축소/투명도, 원래 크기 복원을 막습니다. 복사·저장·OCR·닫기는 사용할 수 있으며, 전역 표시 설정은 계속 적용됩니다. 다음 실행 시 고정 이미지 복원 옵션이 켜져 있으면 잠금 상태도 저장됩니다.
- 캡처 중 커서 주변 원본 픽셀을 **7배 돋보기**로 표시합니다. 십자선으로 위치를 확인하고 드래그하면 됩니다. 돋보기 아래에 선택 영역의 실제 이미지 px를 표시합니다. 기존처럼 마우스 버튼을 놓으면 캡처가 확정됩니다. 돋보기와 십자선은 결과 이미지에 포함되지 않습니다.
- 이미지 우클릭 → **이미지 편집** 또는 **Ctrl+E**: 사각형·화살표·텍스트·모자이크를 추가합니다. 도형과 모자이크는 드래그, 텍스트는 위치를 클릭한 후 입력합니다. 색상, 선 두께, 글자 크기, 모자이크 블록 크기를 조절할 수 있습니다. 크기 단위는 원본 이미지 px입니다.
- **Ctrl+Z / Ctrl+Y**로 편집을 취소하거나 다시 실행합니다. **복사(Ctrl+C)**, **저장(Ctrl+S)**, **결과 새로 고정**은 편집이 합쳐진 원본 해상도 이미지를 출력합니다. 기존 고정 이미지는 수정하지 않습니다. 편집 창을 닫으면 출력하지 않은 편집 내용은 버려집니다.
