# PySnip

Windows 10 이상에서 사용하는 Python / PySide6 기반의 화면 캡처·이미지 고정 프로그램입니다. Snipaste에서 영감을 받아 만들었으며, 이미지 위 직접 그리기와 한국어·영어 OCR, 텍스트 카드, 포터블 설정을 지원합니다.

현재 버전: **0.5.0** · [변경 이력](CHANGELOG.md) · [배포 파일](https://github.com/0707soo/PySnip/releases)

## 설치와 업데이트

1. Release에서 `PySnip-0.5.0-Windows-x64.zip`을 내려받아 쓰기 가능한 폴더에 풉니다.
2. `PySnip.exe`를 실행합니다. Python 설치는 필요하지 않습니다.
3. 업데이트할 때는 프로그램을 완전히 종료한 뒤 **EXE만 교체**합니다. 기존 INI와 이미지 복원 파일은 보관하세요.

최초 실행은 메인 창을 표시하고, 이후에는 트레이로 시작합니다. 트레이 더블클릭 또는 메뉴의 **메인 창 열기**로 창을 표시합니다. 중복 실행하면 기존 창을 엽니다. 메인 창의 X 버튼은 트레이로 숨기며, 완전히 끝내려면 **종료**를 선택합니다. 트레이를 사용할 수 없으면 메인 창을 표시합니다.

## 기본 조작

| 조작 | 기능 |
|---|---|
| F1 | 영역 캡처 후 클립보드 복사·이미지 고정 |
| F2 | 고정 이미지 전체 숨김·복원 |
| F3 | 클립보드 이미지 또는 텍스트 고정 |
| 이미지 드래그 / 휠 | 이동 / 확대·축소 |
| Ctrl+휠 | 전체 고정 이미지의 투명도 조절 |
| Ctrl+C / Ctrl+S | 현재 이미지를 원본 해상도로 복사 / PNG 저장 |
| Ctrl+T | OCR 결과 창 열기·자동 인식 |
| Space | 이미지 위 직접 그리기 시작·종료 |
| Ctrl+E | 별도 이미지 편집 창 열기 |
| Ctrl+L | 이미지별 이동·크기 잠금 |
| Shift+더블클릭 | 썸네일 접기·펼치기 |
| 0 | 썸네일 해제·원래 크기 복원 |
| Esc | 그리기 중이면 그리기 종료, 그 외에는 닫기 확인 |

캡처 중에는 커서 주변을 7배 확대하는 돋보기와 선택 영역의 실제 px 크기를 표시합니다. 드래그를 놓으면 확정하며, Esc나 우클릭으로 취소합니다. 돋보기는 캡처 결과에 포함되지 않습니다.

### 단축키 설정

설정에서 F1/F2/F3에 해당하는 전역 단축키를 변경할 수 있습니다. Ctrl·Alt·Shift와 기능키·영문자·숫자를 조합합니다. 숫자를 선택하면 **Num** 체크박스로 상단 숫자열과 숫자패드를 구분합니다. 숫자패드는 Num Lock을 켜고 사용하세요.

새 기능키 선택 범위는 F1~F11입니다. F12, Win 조합, Alt+F4, 앱 내부에서 사용하는 Ctrl+C/S/T/E/L/Z/Y는 전역 단축키로 지정하지 않습니다. 중복 조합이나 다른 앱이 점유한 조합은 안내하며, 등록 실패 시 기존 단축키를 유지합니다. 기존 INI의 F13~F24는 유지하고 제한된 조합은 설정에서 수정하도록 표시합니다.

## 이미지 표시·복원

- **전역 표시 설정**: 불투명도 20~100%, 외곽선 0~20px. 기본값은 100%, 1px입니다. 모든 고정 이미지에 적용되며 복사·PNG 결과에는 표시용 외곽선이나 창 투명도를 포함하지 않습니다.
- **잠금**: 드래그·휠·원래 크기·썸네일 전환·그리기 시작을 막습니다. 복사·저장·OCR·닫기는 사용할 수 있으며 전역 표시 설정은 계속 적용됩니다.
- **썸네일**: 긴 변 최대 160 논리 px로 접습니다. 펼치면 기존 확대율과 현재 위치를 유지합니다. 복사·저장·OCR에는 전체 해상도를 사용합니다.
- **닫기 확인**: Esc 또는 닫기 메뉴는 확인창을 표시합니다. 기본 선택과 확인창의 Esc는 취소입니다. 모두 닫기는 한 번만 확인하며, 프로그램 종료는 확인하지 않습니다.
- **마지막 닫은 이미지 복원**: 메인 창·트레이에서 최근에 닫은 이미지부터 되살립니다. 보관 개수 기본값은 **0(무제한)**이며, 양수를 설정하면 오래된 기록부터 제외합니다. 이 기록은 메모리에 보관하고 프로그램 종료 시 비웁니다.
- **다음 실행 시 고정 이미지 복원**: 설정에서 켜면 정상 종료 시 열려 있던 이미지·위치·확대율·잠금·썸네일 상태와 텍스트 카드 원문을 저장합니다. 기본값은 꺼짐입니다. 다음 실행에는 숨겨둔 이미지도 표시하고, 화면 밖에 놓인 이미지는 현재 화면으로 옮깁니다. 옵션을 끄고 저장하면 기존 복원 파일도 삭제합니다.

프로그램이 완전히 종료된 동안에는 이미지를 표시하지 않습니다. 강제 종료·충돌 직전 상태의 자동 저장은 지원하지 않습니다. 무제한 닫기 기록의 메모리 사용량은 보관 이미지 수에 따라 늘어납니다.

## 직접 그리기와 편집

**Space** 또는 우클릭 → **이미지 위에 그리기**를 선택하면 고정 이미지에서 바로 작업합니다. **Ctrl+E**는 별도 편집 창을 열어 기존 이미지를 유지하면서 결과를 복사·저장·새로 고정합니다.

지원 도구는 **펜, 형광펜, 사각형, 타원, 화살표, 텍스트, 모자이크**입니다. 선·도형은 드래그하고 텍스트는 위치를 클릭한 후 입력합니다. 크기는 원본 이미지 px 기준입니다. Ctrl+Z/Y로 실행 취소·다시 실행, 우클릭으로 진행 중인 선을 취소합니다.

형광펜은 기본 노란색, 두께 20px, 진하기 40%입니다. 두께 4~100px와 진하기 10~80%를 조절할 수 있으며 아래의 검은 글자가 보이도록 합성합니다. 한 획 안에서 겹친 부분의 진하기는 일정하고, 새 획을 여러 번 겹치면 진해집니다. 일반 펜과 형광펜은 색상·두께를 각각 기억합니다.

**색상 팔레트**는 기본 24색, `#RRGGBB` 입력, 사용자 색상 선택을 제공합니다. 즐겨찾기는 추가·제거 즉시 INI에 저장하고 모든 편집 창에서 공유합니다. 색상 적용을 취소해도 즐겨찾기 변경은 유지됩니다.

직접 그린 결과는 고정 이미지의 복사·저장·OCR·복원에 포함됩니다. 해당 이미지가 열려 있는 동안 그리기를 다시 시작하면 실행 취소 기록을 사용할 수 있습니다. 이미지나 프로그램을 닫은 뒤 복원할 때는 합쳐진 결과를 복원하며 실행 취소 기록은 초기화됩니다. 별도 편집 창을 닫으면 출력하지 않은 편집 내용은 버려집니다.

## 텍스트 카드

이미지 없이 텍스트만 복사한 상태에서 **F3**을 누르면 텍스트를 이미지 카드로 표시합니다. 이미지와 텍스트가 함께 있으면 이미지가 우선합니다. 클립보드의 원문은 바꾸지 않습니다.

카드 우클릭 메뉴에서 **원문 텍스트 복사** 또는 **텍스트 카드 편집**을 선택합니다. 내용·글자 크기(10~64px)·너비(200~1000px)·글자색·배경색을 변경할 수 있으며 색상 즐겨찾기도 공유합니다. 원문과 서식은 이미지 복원 시 함께 유지됩니다.

직접 그린 주석이 있는 카드의 텍스트를 수정하면 주석이 초기화되므로 적용 전에 확인합니다. HTML은 실행하지 않고 일반 텍스트로 표시합니다. 한 카드의 최대 길이는 20,000자, 높이는 4096 논리 px이며 초과 시 내용을 나누도록 안내합니다.

## 한국어·영어 OCR

1. **설정 → OCR → OCR 언어 활성화 / 설치 상태**에서 언어 상태를 확인합니다.
2. 언어가 없으면 한국어·영어 활성화를 선택하고 Windows 관리자 승인을 허용합니다. 설치에는 인터넷과 Windows Update 접근이 필요할 수 있습니다.
3. 고정 이미지에서 **Ctrl+T**를 누르면 자동 인식 후 텍스트만 표시합니다. 결과를 수정하거나 선택하여 복사할 수 있습니다.

Windows 내장 OCR과 Windows PowerShell 5.1을 사용합니다. 이미지·텍스트를 외부 서버에 보내지 않으며 OCR 임시 이미지는 작업 종료 시 삭제합니다. 기본 인식 언어는 한국어입니다. 선택한 언어가 없으면 설치된 다른 지원 언어를 사용합니다.

- **확대 후 인식 시도**: 하지 않음 / 2배 / 4배, 기본 2배. 원본에서 글자를 찾지 못하거나 인식 엔진이 실패하면 선택한 배율로 한 번 재시도합니다. 확대 과정은 화면에 표시하지 않습니다.
- **인식 결과 자동 복사**: 기본 꺼짐. 켜면 비어 있지 않은 성공 결과만 복사하며 오류·취소·빈 결과는 기존 클립보드를 유지합니다.

OCR 언어 구성 요소는 PC별로 설치합니다. 회사의 Windows Update 정책 등에 따라 설치가 제한될 수 있습니다. 두 언어 결과 자동 병합과 표 서식 복원은 지원하지 않습니다. 언어 설치 중 앱을 종료해도 이미 시작된 Windows 설치 작업은 계속될 수 있습니다.

## 포터블 데이터

EXE와 같은 폴더에 다음 파일을 생성합니다. 소스로 실행하면 프로젝트 폴더를 사용합니다.

| 파일 | 내용 |
|---|---|
| `PySnip.ini` | 단축키·표시·OCR·보관 개수·색상 즐겨찾기·실행 이력 |
| `PySnip.session.json` | 이미지 복원 옵션 사용 시 이미지 데이터와 창 상태·텍스트 카드 원문 |

포터블 이동 시 EXE와 위 파일을 함께 옮기세요. ZIP과 Git에는 개인 설정·이미지 데이터를 포함하지 않습니다. INI를 직접 수정하려면 앱을 종료한 뒤 편집합니다. INI가 처음 생성될 때만 남아 있는 구버전 레지스트리 설정을 가져옵니다.

## 개발과 검증

검증 환경은 Windows 10 x64, Python 3.13입니다.

```powershell
python -m pip install -r requirements.txt
python main.py
python -m unittest discover -s tests -v
```

빌드는 명시적으로 요청한 경우에만 진행합니다.

```powershell
python -m pip install pyinstaller pillow
python build_release.py
```

빌드 스크립트는 테스트 → 원본 SVG에서 ICO 생성 → PyInstaller 단일 EXE 생성 → EXE 자체 검사 → ZIP 패키징 순서로 동작합니다. 결과는 `dist/PySnip.exe`와 `dist/PySnip-0.5.0-Windows-x64.zip`입니다. ZIP에는 EXE, README, CHANGELOG를 담습니다. 생성되는 `PySnip.spec`, ICO, 중간 빌드 파일과 검증 로그는 Git에서 제외합니다.

버전은 `version.py`, 변경 이력은 `CHANGELOG.md`에서 관리하며 배포 태그는 `v0.5.0` 형식입니다.

## 현재 제한

각 모니터 안의 영역 캡처를 지원합니다. 여러 모니터에 걸친 하나의 영역 선택, 창 자동 인식, 이미지 그룹, 클릭 통과는 아직 지원하지 않습니다. 고정 이미지는 다음 화면 캡처에도 포함됩니다. 혼합 DPI·다중 모니터 구성은 실제 환경에서 추가 확인이 필요합니다. 배포 EXE에는 코드 서명이 없습니다.
